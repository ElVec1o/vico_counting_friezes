# Data

`T5.txt`  T(N,5) for N = 1..40, proved-complete (search bound p,q <= N^3+2N^2).
`T6.txt`  T(N,6) for N = 1..20, proved-complete (search bound p*q <= 2N^2(N+1)).

See `CORRECTIONS.md` for the values an earlier circulated note got wrong, and why.

Every value is produced by an enumeration whose search range is proved in the paper.
No value here relies on a count stabilising under an increasing cutoff.

## Status of these numbers

The enumeration procedure that produced them is a theorem, not a heuristic:
`VicoEnum.W5_setOf_eq_box` proves the width-5 solution set is exactly the filtered box,
so nothing is missed, and `VicoEnum.W6_mem_box` is the width-6 analogue. The search
bounds those rest on are `VicoEnum.width5_bound` and `VicoEnum.width6_bound`.

Kernel evaluation additionally checks T(N,5) for N = 1..5 (`VicoEnum.T5_one` through
`T5_five`). Beyond that the Lean kernel aborts: the box has size of order N^3 and
`decide` fails with SIGABRT at N = 6, which is a hard limit of kernel evaluation over
`Finset.filter` rather than a budget that can be raised.

The remaining entries here are the output of the proved procedure, regenerated by the
committed scripts. They are computations, not theorems, and the paper says so.

## atomB.csv

For each prime `5 <= p < 6*10^4`: the number of `t` contributing to `C(p)` in the
decomposition of Section 8, the value of `C(p)` itself, and the largest single term.
Generated by `code/atom_b.rs`; the block statistics quoted in the paper are recomputed
from it by `code/atom_b_stats.py`.

## T5_primes.csv

T(p,5) for every prime p < 500, from the proved-complete width-5 enumeration
(search bound a,b <= N^3+2N^2, VERIFIED as VicoEnum.width5_bound). Generated by
code/t5_primes.rs, which reports progress and ETA and checkpoints atomically after
each prime.

The sequence is not monotone in p. Over 2 <= p < 500 the count drops at roughly
39 to 49 per cent of consecutive prime pairs, with drops as sharp as
T(419,5) = 390 followed by T(421,5) = 130. It does not appear in OEIS, and it is not
matched by any of d(p-1), d(p+1), d(p^2-1), sigma(p-1), omega(p^2-1) or their common
combinations, nor is it governed by the residue class of p modulo 3, 4, 5, 6, 8, 12
or 24. Explaining it is open.
